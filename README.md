# Fullstack-MaisPraTi

Este repositório reúne todas as atividades e listas de exercícios do curso **Fullstack MaisPraTi**, em parceria com a **Codifica Edu**. O curso tem como objetivo desenvolver habilidades práticas em programação, com foco no mercado de trabalho e na formação de profissionais **Júnior** na área de desenvolvimento Fullstack.

## Sobre o Curso

O curso oferece exercícios e projetos que abrangem desde conceitos iniciais até práticas mais avançadas de desenvolvimento web e backend, preparando o aluno para atuar como **desenvolvedor Júnior**.  

- Aprendizado prático com listas de exercícios e desafios.
- Conteúdo estruturado para consolidar fundamentos e boas práticas.
- Desenvolvimento de projetos que simulam situações reais de mercado.
