# Cafeteria BomGosto ☕

Este repositório contém os scripts SQL para o controle de vendas da cafeteria BomGosto.

## Estrutura do projeto

- `create_tables.sql` → Criação das tabelas do banco de dados.  
- `insert_data.sql` → Inserção de dados de exemplo para testes.  
- `q1_listar_cardapio.sql` → Listagem do cardápio.  
- `q2_listar_comandas_itens.sql` → Listagem das comandas e itens vendidos.  
- `q3_total_comanda.sql` → Valor total de cada comanda.  
- `q4_comandas_multicafe.sql` → Comandas com mais de um tipo de café.  
- `q5_faturamento_por_data.sql` → Faturamento total por data.

## Como executar

1. Execute `create_tables.sql` para criar o banco.
2. Execute `insert_data.sql` para popular as tabelas.
3. Rode os arquivos `q1_...` a `q5_...` conforme a numeração das questões.
